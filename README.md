# John Woo Presents Stranglehold 컬렉터스 에디션 한글패치 (PS3)

PS3판 **John Woo Presents Stranglehold** 북미판 **컬렉터스 에디션**(BLUS30081)을 한국어로 즐길 수 있게 해 주는 비공식 한글패치입니다.
일반판 한글패치 v1.0의 내용을 모두 담고 있고, 컬렉터스 에디션에 수록된 영화 **첩혈속집(Hard Boiled)**에도 한글 자막을 넣었습니다.

> 일반판(BLUS30080)을 가지고 계시다면 일반판 한글패치 저장소를 이용하세요. 이 패치는 컬렉터스 에디션에만 적용됩니다.

| 항목 | 내용 |
|---|---|
| 대상 | John Woo Presents Stranglehold (USA) — 컬렉터스 에디션 **BLUS30081** |
| 패치 버전 | **v1.0 CE** (일반판 한글패치 v1.0 기준 + 영화 자막) |
| 지원 환경 | RPCS3, PS3 실기(CFW / HEN) |
| 적용 방식 | 폴더형 게임 설치, ISO 적용 |
| 별도 패치(yml) | **필요 없음** |
| 패치 용량 | 약 2MB (게임 데이터 미포함) |

---

## 주요 내용

- **UI·메뉴·미션 텍스트 전체 한글화**: 메뉴, 일시정지 화면, 미션 목표, 로딩 팁, 상점, 챕터 선택, 조작 설정, 오류 메시지 등
- **원작 느낌의 한글 폰트**: 제목·본문·강조 폰트를 원작 스타일에 맞춰 각각 따로 제작
- **영상(Bink) 컷신 자막**: 원래 자막이 없던 컷신 16개에 한글 자막 추가 (300줄 이상)
- **실시간(인게임) 컷신 자막**: 게임 엔진으로 재생되는 컷신 21개에 한글 자막 추가
- **수록 영화 첩혈속집(Hard Boiled) 한글 자막**: 게임에 수록된 영문 자막 1,157줄 전체를 직접 번역 (싱크는 원본 그대로)
  - 말투가 다른 두 가지 판을 제공합니다. **기본판**(영화 자막체, 인물 관계에 따라 반말 위주)과 **존댓말 혼합판**(앨런과 테킬라, 테레사 등이 서로 존댓말)
- **게임 중 대사 자막**: 보스 도발, 스피커 방송, 헬기 무전, 미션 중 대화, 존 우 상점 대사 등 약 500줄
- **큰 자막 폰트**: 자막을 TV 화면에서도 읽기 쉬운 크기로 표시
- **yml 불필요**: 파일 무결성 검사 모듈까지 함께 패치하므로 RPCS3 게임 패치(yml) 없이 바로 실행됩니다.

## 패치 방식

이 패치에는 **게임 파일이 들어 있지 않습니다.** 원본 파일과 한글패치 파일의 **차이 정보**(번역 텍스트, 폰트, 자막 등 바뀐 부분)만 들어 있으며,
설치할 때 사용자의 원본 게임 파일을 읽어 한글패치 파일을 직접 만들어 적용합니다.
원본 파일이 다르면(다른 지역판, 이미 수정된 파일 등) 아무것도 바꾸지 않고 멈춥니다.

## 준비물

- Stranglehold 북미판 컬렉터스 에디션(BLUS30081) 게임 데이터 (본인 소유 디스크에서 직접 추출한 것)
  - **폴더 형태**(`PS3_GAME` 폴더가 들어 있는 폴더) 또는 **복호화된 ISO**
- Windows PC (설치 스크립트 실행용, PowerShell 기본 포함)

## 설치 방법

[Releases](../../releases)에서 원하는 판(기본판 / 존댓말 혼합판)의 압축 파일 하나를 받아 아무 곳에나 풉니다. (`patch_data` 폴더를 포함한 폴더 구조를 그대로 두세요)

### 방법 1. 폴더 형태의 게임에 적용

1. `한글패치_설치.bat` 실행
2. 폴더 선택 창에서 게임 폴더(`PS3_GAME` 폴더가 들어 있는 폴더)를 선택
3. 완료 메시지가 나오면 끝입니다.

- 바뀌는 원본 파일은 게임 폴더 안 `_한글패치_원본백업` 폴더에 자동으로 보관됩니다.
- 컬렉터스 에디션(BLUS30081)이 아닌 게임 폴더를 고르면 적용하지 않고 멈춥니다.

### 방법 2. ISO에 적용

1. `한글패치_ISO적용.bat` 실행
2. 파일 선택 창에서 원본 ISO 선택
3. 같은 폴더에 `원본이름 (KOR).iso`가 새로 만들어집니다.

- **원본 ISO는 수정하지 않습니다.**
- 원본 크기(약 20.7GB) + 약 0.6GB의 여유 공간이 필요합니다. (용량이 커서 복사에 시간이 꽤 걸립니다)
- 만들어진 ISO는 ISO9660/Joliet 형식입니다. (PS3 ISO 제작 도구와 같은 형식)

## 제거 방법

- **폴더 형태**: `한글패치_제거.bat` 실행 후 같은 게임 폴더 선택 → `_한글패치_원본백업`으로 원래 파일이 복원됩니다.
- **ISO**: 만들어진 `(KOR).iso`를 지우면 됩니다. 원본 ISO는 그대로입니다.

## 실행 환경별 안내

### RPCS3
- 패치한 게임 폴더(또는 ISO)를 그대로 실행하면 됩니다.
- 이 게임용으로 다른 무결성 검사 해제 패치(yml)를 켜 두었다면 꺼도 됩니다.

### PS3 실기
- **CFW 또는 HEN** 환경이 필요합니다. (패치된 무결성 검사 모듈이 비서명 형식이기 때문)
- 폴더 형태는 webMAN / multiMAN 등으로, ISO는 webMAN 등으로 마운트해 실행합니다.

## 알려진 사항

- 실시간 컷신과 게임 중 대사는 원문 자막이 없어 **음성을 받아 적어 번역**했습니다. 잘못 들은 부분이 있을 수 있습니다.
  - 알아듣기 어려운 대사 4줄과 신음·비명 같은 효과음에는 자막을 넣지 않았습니다.
- 법적 고지(Legal), 제작진(Credits) 텍스트는 영어 그대로입니다.
- 실기 동작은 제작자가 직접 확인하지 못했습니다. 문제가 있으면 [Issues](../../issues)에 남겨 주세요.
- 일반판(BLUS30080)과 다른 지역판에는 적용되지 않습니다.
- 영화 자막은 게임에 들어 있는 영문 자막을 바탕으로 번역했습니다. 영문 자막에 없는 대사(배경 대화 등)에는 자막이 없습니다.

## 문제 제보

[Issues](../../issues)에 아래 내용을 함께 적어 주시면 확인이 빠릅니다.
- 실행 환경 (RPCS3 버전 / 실기 펌웨어)
- 적용 방식 (폴더 / ISO)
- 문제가 생긴 챕터·장면 (가능하면 스크린샷이나 영상)

## 저작권 및 면책

- 이 패치는 **비공식 팬 번역**입니다. 원작 게임과 관련 상표의 권리는 Midway Games를 비롯한 각 권리자에게, 수록 영화 첩혈속집(Hard Boiled)의 권리는 영화의 권리자에게 있으며, 이 패치는 권리자와 관련이 없습니다.
- 영화 자막은 게임에 수록된 영문 자막을 제작자가 직접 번역한 것이며, 영화 영상이나 음성은 포함되어 있지 않습니다.
- 배포 파일에는 **게임 데이터가 들어 있지 않습니다.** 설치할 때 사용자가 가진 원본 파일을 읽어, 바뀐 부분(번역문, 한글 글리프 등)만 적용합니다. 그래서 정품 게임 데이터가 반드시 필요합니다.
- 예외적으로 파일 무결성 검사 모듈(`libPS3ShaHashes.sprx`)은 원본이 암호화되어 있어 차이만으로 만들 수 없기 때문에, 해시값을 갱신한 모듈(파일 목록과 해시값으로 이루어진 작은 데이터 모듈)이 차이 정보 안에 포함되어 있습니다.
- 게임 파일이나 ISO 자체를 공유하지 마세요. 이 저장소에서도 게임 파일은 배포하지 않습니다.
- 패치 사용으로 생기는 문제에 대해 제작자는 책임지지 않습니다. 적용 전 원본을 백업해 두세요.

## 구성 파일

| 파일 | 설명 |
|---|---|
| `한글패치_설치.bat` / `install.ps1` | 폴더 형태 게임에 설치 |
| `한글패치_제거.bat` / `uninstall.ps1` | 폴더 형태 설치 되돌리기 |
